# Icons (stroke SVG)

Centerline-traced from the first-version PNG icons.
Transparent background. **Stroke-only** (no fill), for PPT/Illustrator outline-color controls.
AGV right-side arrow removed.

## Recolor

Replace:

```
stroke="#1E3A5F"
```

Examples:
- Human `#3E6EC8`
- AGV `#10CB88`
- Robot `#F7A878`
- Gantry `#90C0E8`
- Material `#F8D83F`
- Others `#D8D0F0`

Do **not** set a fill; keep `fill="none"`.
